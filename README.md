AIKTC Campus Navigation Route Finder

A web-based application for finding routes and navigating the AIKTC campus.

Prerequisites

Install the following before starting the project:

Node.js 22
npm
GCC

Verify the installations:

``` node --version ```
``` npm --version ```
``` gcc --version ```

Setup
1. Navigate to the frontend

Open a terminal in the project directory and run:

``` cd .\frontend\ ```

2. Install dependencies

Install the required npm packages:

``` npm install ```

3. Start the development server

Run the application:

``` npm run dev ```


The terminal will display the local development URL. Open that URL in your browser.

Example:

``` http://localhost:5173/ ```

Quick Start

For a fresh setup, run:

``` cd .\frontend\ ```
``` npm install ```
``` npm run dev ```
